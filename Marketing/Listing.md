# Khaos Palette: Fab listing

## Title

Khaos Palette

## Short description

The props you place most, one click from the level.

## Description

Set dressing means reaching for the same props again and again. Khaos Palette keeps them in one tab beside the
viewport, sorted the way you work.

Click a tile, then click where it goes. Pin the tab to the side and it fades out of the way while you build. Palettes
are plain assets, so the whole team dresses levels from the same set.

Editor-only. Nothing ships in your game.

## Technical details

- **Code modules:** `KhaosPaletteRuntime` (Runtime, the palette data asset), `KhaosPaletteEditor` (Editor)
- **Number of Blueprints:** 0
- **Number of C++ classes:** 3 UObject classes, 2 structs
- **Network replicated:** No
- **Supported development platforms:** Windows
- **Supported target build platforms:** Windows, Mac, Linux, Android, iOS
- **Supported engine versions:** 5.8
- **Documentation:** https://github.com/KhaosSystems/KhaosPalette/blob/main/Content/Docs/KhaosPalette.md
- **Important notes:** Create a palette with Content Browser > Add > Khaos > Khaos Palette. Open it with the Palette
  button on the toolbar.
